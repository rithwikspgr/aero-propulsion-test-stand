# Aero Propulsion Static Test Stand

A 3mm MDF static test stand for 24mm D-class rocket motors, designed as a 1-week rapid-prototype project.

![Assembled Test Stand](Final_Assembled%205.jpeg)

## 1. Project Goal
To design and build a complete system that hits four criteria:
* **CAD:** 3D assembly designed in Onshape.
* **System Modelling (Code):** A Python script to simulate the D12's thrust curve. See the script here: [motor_sim.py](motor_sim.py)
* **Fabrication:** Parts nested and cut from 3mm MDF on a laser cutter.
* **Execution:** Full design-to-build cycle completed in 7 days.

## 2. Key Components
* 5-part main frame (Base, 2x Side Walls, 2x End Walls)
* 1x Fixed Rear Motor Bulkhead (tabbed)
* 1x Plunger/Sliding Bulkhead (no tabs)
* 1x Sensor Bulkhead (tabbed)

## 3. Technologies Used
* **CAD:** Onshape
* **Fabrication:** Inkscape (for nesting), Laser Cutter
* **Material:** 3mm MDF
* **Simulation:** Python (Matplotlib, Numpy)
